MEMAAR DESIGN GROUP - DEMO WEBSITE

How to open:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox.

Files:
- index.html: website structure and text
- styles.css: visual design and responsive layout
- script.js: menu, animations, filters and demo contact form
- assets/: project images sourced from the supplied company profile PDF

Important before publishing:
- Confirm all company contact details.
- Replace any low-resolution portfolio images with original project photographs.
- Connect the enquiry form to EmailJS, Formspree or a custom backend.
- Add verified testimonials and project statistics only after receiving them from the client.
